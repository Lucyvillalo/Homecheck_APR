# CasaCheck

Proyecto Android Kotlin creado desde cero como MVP local para documentar inspecciones antes y después de un alquiler o evento.

## Abrir

Abre esta carpeta en Android Studio y sincroniza Gradle. El proyecto usa Jetpack Compose y solicita Android SDK 37, Gradle 9.3.1 y Java 17.

## Flujo disponible

- Crear inspección residencial o de eventos.
- Revisar ambientes e inventario con estados, cantidades y observaciones.
- Capturar foto desde la cámara del dispositivo; las fotos se guardan localmente con fecha y hora.
- Firmar en pantalla por ambas partes, generar un acta PDF y compartirla.
- Iniciar inspección Después a partir de un acta Antes y revisar cambios.

## Alcance de esta base

Los datos se guardan localmente en el dispositivo. Firebase, cuentas y sincronización en la nube quedan pendientes de conectar con la configuración del equipo. La ubicación GPS tampoco está incluida en esta primera base.
